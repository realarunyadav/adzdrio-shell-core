# Adzdrio Core Platform

Build ABOS Final (Adzdrio Business Operating System).

ABOS is an enterprise-grade internal business operating system for Adzdrio India Services Pvt. Ltd.

This is NOT just a CRM. It is a modular enterprise platform that will eventually include CRM, HRMS, Finance, Inventory, Projects, Marketing, AI, Analytics, Automation and other business applications.

Tech Stack:

- React

- TypeScript

- Vite

- TanStack Router

- Tailwind CSS

- shadcn/ui

Project Requirements:

- Generate ONLY the enterprise application shell.

- Do NOT generate any business modules.

- Do NOT generate authentication.

- Do NOT connect Supabase.

- Do NOT create any database.

- Do NOT create API integrations.

- Do NOT generate demo business data.

- Do NOT create backend logic.

Only create:

- Enterprise design system

- Global layout

- App shell

- Navigation architecture

- Route architecture

- Module registration system

- RBAC foundation (frontend only)

- Theme system

- Shared UI components

- Configuration structure

The application must be highly modular, scalable, maintainable and suitable for long-term enterprise development.

Wait for architecture instructions before implementing any business functionality.
